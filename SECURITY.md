# Security policy

Telegraph is pre-1.0. Only the latest release receives fixes.

Report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/ao3575911/telegraph/security/advisories/new),
not in public issues. Expect an acknowledgement within 7 days.

In scope: signature, hash-chain, checkpoint-quorum, pin and swap-fold
logic, and anything that lets one key take or freeze another key's handle.
